# RMCL 内置联机节点清单
#
# 一行一个节点，支持的写法与 EasyTier 的 --peers 一致：
#   tcp://1.2.3.4:11010
#   udp://1.2.3.4:11010
#   wss://example.com/path
#
# 需要备注时可以写成「备注|地址」，备注只用于展示，不影响连接：
#   社区节点|tcp://1.2.3.4:11010
#
# 规则：
#   - 以 # 开头的行、空行会被忽略
#   - 格式不合法的地址会被丢弃，最多只取前 16 个
#   - 拉取失败时保留客户端原有节点，不会清空
#
# 客户端不会自动更新：只有在「设置 → 联机 → 高级设置 → 更新节点」
# 被玩家主动点击时，才会拉取这个文件。
#
# 注意：房主与加入者必须连接到至少一个相同节点才能互相发现，
# 所以这里保留的节点越通用越好，不建议放只对少数人可用的私有节点。
#
社区节点|tcp://183.66.27.22:39409
